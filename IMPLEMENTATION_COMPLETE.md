## 🚀 Ready to Use

### Immediate Usage

```bash
# Clone the repository
git clone https://github.com/appbuilder2903/Vive-code.git
cd Vive-code

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your API keys

# Start services
docker-compose up -d

# Start development
npm run dev

# Access at http://localhost:3000
```
