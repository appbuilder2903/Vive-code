### 📚 Usage Guide

#### Creating Files/Folders
1. **Click** the + icon in file explorer header
2. **Right-click** on a folder → New File/Folder
3. **Enter** name and press Enter

#### Editing Files
1. **Click** file in explorer to open
2. **Type** to edit (auto-save active)
3. **Blue dot** indicates unsaved changes
4. **Ctrl/Cmd + S** to save immediately

#### Running Code
1. **Select** a file
2. **Click** Run button or press **Ctrl/Cmd + Enter**
3. **View** output in terminal panel
4. **Clear** output with Clear button

#### Deleting Files
1. **Right-click** file or folder
2. **Select** Delete
3. **Confirm** in dialog

#### Renaming Files
1. **Right-click** file or folder
2. **Select** Rename
3. **Type** new name
4. **Press** Enter or click away
